# Historical-neutral ornament alternative — 2026-08-21

Status: generation complete; local visual and technical audit passed. Image-only
scope; no application integration.

User review: positive — the user called this a genuinely strong alternative.
Living Manuscript remains the main design; this folder remains the deliberately
neutral historical option.

## Direction lock

The existing `universal/ornaments/living-manuscript/` Living Manuscript set
remains the primary Quillverse ornament direction. This round adds a separate
alternative, not a replacement.

The alternative must feel like real surviving material from unspecified old
times: aged parchment, iron-gall ink, plain sealing wax, restrained hand ruling,
subtle engraving, wear, fibers, stains, and imperfect human craft. It must not
signal a specific fictional world, Regency society, high fantasy, magic,
celestial lore, botanical romance, steampunk, or modern graphic design.

## Shared generation constraints

- Realistic historical materials and physical wear.
- World-neutral and era-broad; approximately pre-industrial manuscript culture.
- No flowers, leaves, vines, fantasy symbols, portals, glowing effects, runes,
  constellations, heraldic creatures, crowns, romance motifs, or readable text.
- No Quillverse logo: this is the unbranded fallback option.
- Overlay assets require genuine transparent PNGs; panel and relationship
  background are intentionally opaque.
- Existing primary ornaments remain untouched.
