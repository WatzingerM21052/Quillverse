# Universal visual templates

Reusable, world-neutral composition and style references for Quillverse.

The current review batch lives in dated `review-2026-08-21/` folders beneath
`maps/`, `characters/`, and `locations/`. These are references for composition,
identity consistency, pin-safe map terrain, and dialogue-safe environment
framing. They are not literal assets that every future world must reuse.

Exact prompts and the local visual audit are in
`../docs/universal-template-round-2026-08-21.md`.

Three greener continuations of the dynamic manuscript Map 3 are stored under
`maps/refinement-2026-08-21/`: lush sage, temperate green, and rain-washed.
Their exact edit prompts and comparison audit are in
`../docs/final-light-dark-map-cutout-round-2026-08-21.md`.

Status: review only; no application integration is authorized.
