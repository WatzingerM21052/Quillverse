# Visual archive

Preserved non-current visual work. Nothing here should be used as a default or
application asset without first checking the catalog entry.

## Folder meanings

- `alternatives/`: technically usable images that were explicitly
  deprioritized or never selected.
- `references/`: visually valuable form references that are technically
  unsuitable for direct use.
- `superseded/`: older versions and byte-identical historical package/source
  copies replaced by a clearer canonical file elsewhere in the library.
- `technical-failures/`: measurable defects such as painted checkerboards,
  incorrect alpha, render artifacts, or geometry drift.

The archive replaces the former mixed-language `Experimentelles/` tree. It is
organized by reason first, then by asset family, so future sessions can tell why
a file is archived without opening it.
